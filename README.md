# 📌 프로젝트 소개
이 리포지토리는 SLSL의 AI 연구 파트에 해당하는 저장소입니다. 
본 프로젝트에서는 조선왕조실록 기반 역사 학습 AI 챗봇을 개발하였으며 
챗봇의 답변 정확도를 높이기 위해 bert + llama2 두 개의 AI 모델을 결합하고 
학습을 위한 QA 데이터셋과 퀴즈 데이터셋 모두 직접 구축하였습니다. 
또한 개발된 모델은 백엔드 API로 제공되어 실제 서비스로 연동되었습니다. 


# 🧠 주요 기능
### 1. 한국어 분류 모델 + 다국어 LLM 모델 결합 (bert + llama2)
  - 사용자 질문의 의도를 파악하고 주제에 적합한 응답을 생성하기 위해 두 개의 AI 모델 결합
  - 자체 제작한 데이터셋을 기반으로 성능 개선 및 파라미터 최적화 진행

### 2. 사용자 질문 - 응답 데이터셋 직접 구축
  - 조선왕조실록과 한국민족문화대백과 사전을 기반으로 한 질문과 이에 대한 응답 데이터를 수작업으로 구축
  - 품질 향상을 위해 라벨을 줄이고 데이터셋 갯수를 늘리는 작업 수행

### 3. 백엔드 API 연동 및 응답 최적화
  - 모델을 백엔드 서버에 연동하여 프론트엔드가 사용할 수 있는 API 형태로 제공
